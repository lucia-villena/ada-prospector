# Etapas del prospecto

Clasificá la conversación en **una** de estas etapas, con evidencia. No fuerces una clasificación si no hay evidencia suficiente: decí "Etapa probable: X" (o "no hay evidencia para clasificar") y explicá en una o dos frases por qué.

| Etapa | Qué se ve en la conversación |
|---|---|
| Prospecto identificado | El alumno tiene un posible cliente y una señal de necesidad, pero todavía no hubo contacto |
| Primer contacto | El alumno mandó el primer mensaje; el prospecto todavía no contestó, o contestó apenas un saludo |
| Conversación iniciada | Hay intercambio real, pero todavía no se habló de cómo resuelve hoy ni de qué necesita |
| Necesidad detectada | El prospecto contó cómo resuelve hoy o qué le duele (volumen, frecuencia, método actual) |
| Propuesta presentada | El alumno explicó el servicio (y, si corresponde, el porcentaje y la referencia) |
| Objeción | El prospecto puso una duda o resistencia concreta (precio, confianza, "ya tengo quien lo hace", "lo pienso") |
| Negociación | Se discuten condiciones: porcentaje, volumen, plazo, modalidad |
| Cierre pendiente | Hay acuerdo o interés claro, falta el paso final: primera operación de prueba, datos, horario |
| Primer cliente / operación | Se coordinó o se hizo la primera operación |
| Seguimiento | Hubo contacto previo y el alumno está retomando o manteniendo la relación |
| Cliente recurrente | Ya operaron más de una vez o hay una frecuencia acordada |
| Sin respuesta | El prospecto dejó de contestar (medí el tiempo desde el último mensaje) |
| Perdido / no calificado | Dijo que no, o no encaja (busca solo precio, origen de fondos poco claro, fuera del método, no recurrente) |

En el campo `etapa` del bloque `<resumen>` escribí el nombre **exacto** de la primera columna (por ejemplo `Propuesta presentada` o `Primer cliente / operación`), sin agregar palabras. Si no hay evidencia para clasificar, dejalo vacío.

## Cómo decidir

- Guiate por lo que **pasó**, no por lo que el alumno quería que pasara.
- Si hay señales de dos etapas (por ejemplo objeción dentro de una propuesta), elegí la que define el próximo paso y mencioná la otra.
- Si el chat está cortado o empieza a mitad, avisalo: la etapa puede ser otra.
- Usá las marcas de tiempo del chat cuando existan: cuánto tardó el alumno en responder, cuánto lleva sin respuesta el prospecto. Si el prospecto respondió y pasaron más de 2 horas sin que el alumno conteste, es un error de velocidad; si pasaron más de 60 días sin contacto, la relación se considera perdida.
- **No quemes etapas:** no propongas cerrar si todavía no se detectó la necesidad, ni cotizar antes de diagnosticar.
